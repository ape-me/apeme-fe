Speed, honestly

WhatNowWhy
Trade → phoneabout 1sSolana confirm is most of it. The chain's own clock runs 1 to 4s behind wall time.
Cached read50 to 100msServed from Cloudflare's edge, no DB hop.
Uncached read100 to 600ms, jitteryThis VPS is shared and overloaded: load 6 to 11, swap in use. The tunnel hop wobbles with it.
On the production VPS, dedicated to indexer + Postgres only, the tunnel hop should sit near 30ms flat and uncached reads under 150ms. Nothing in the code changes for that move: new box, same install, point the tunnel at it.
