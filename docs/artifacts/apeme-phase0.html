The flow

What we decode

Build steps

  1. Repo + schema. Cargo workspace, Postgres on the VPS, migrations for 7 tables.check: migrate up, migrate down
  2. Decoders, offline. Six programs, structs from the verified IDLs. Run on 20 saved real txs each.check: price = Raydium / pump.fun for every tx
  3. Stocks + USD. Load 470 mints from StonkFun. DexScreener loop, 30 mints per call, 30s.check: SPYx = 764.13 ± live
  4. Backfill. Every existing stonk token from Raydium, pump.fun, DBC. Klines where they exist, else RPC trade history.check: STONK500 chart = Raydium's
  5. Live stream. Nexus gRPC, per-program subscriptions filtered by stock mints. Cursor resume.check: kill, restart, no gap
  6. API + WebSocket. Five endpoints, two rooms, all reads from memory or by key.check: p95 < 20ms
  7. Soak. Run one hour next to Raydium's page.check: prices match, zero missed trades

Steps 1 to 4 and 6 need no Nexus key. Step 5 starts the moment the endpoint and key arrive.

Not in phase 0

Fees, cashback, vesting, LP, creator claims, boosts. Stock tokens' own SOL and USDC pools. Holder counts. KOL anything. Robinhood Chain.
