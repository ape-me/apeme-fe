ape-be Design

ape-be

Hono on Cloudflare Workers. The service the phone talks to. It owns no data: it reads what the indexer wrote and pushes what the indexer sends.

What runs where

Why Workers, why not the rest

Workers
Your platform, faster reads, nothing to babysitTwo products shipped on it already. Reads are served from the edge near the user. Scales sockets without thought. About $12 a month at 10K traders.
not Rust here
Rust stays in the indexerPhase 2 is Privy, Jupiter and transaction building, all TypeScript-first. Writing speed is the constraint for eight days.
not D1
One record, not twoPostgres on the VPS is where the indexer writes. A D1 copy would need syncing, and syncing is where bugs live.
not Redis
Durable Objects replace pub/subThe indexer sends trades over signed HTTPS to the Worker, which hands them to the token's room, which fans out. Outgoing socket messages are free on Cloudflare.
not KV for live
KV is eventually consistentA price written in Europe can take up to a minute to show in Asia. KV holds the stock list and images only. Live numbers travel through Durable Objects and Hyperdrive.

Reuse, the rule

thin routes
A handler is ten linesValidate with zod, call one service function, return. No SQL, no math in handlers.
fat services
One function per facttokenHeader(mint), candles(mint, tf, limit), stockTokens(mint, sort, page). REST calls them. The floor diff calls the same ones. Phase 2's ape flow will too.
dumb repos
Every SQL statement in one fileNamed, typed, one query per function. Change a column once.
one contract
Shared shapes, one placeEvery response and the ingest message are zod schemas in contract.ts. They validate what leaves the server and generate the iOS models. Change once, both sides break loudly.
stateless
Nothing lives only hereRooms hold sockets, not truth. Kill everything, phones reconnect and reload from Postgres.

Security, what is actually done

no open ports
TunnelThe VPS listens on localhost only. Cloudflare connects out to it. IP never public, no 80 or 443 open.
read-only
Its own Postgres user with SELECT onlyIf the Worker is ever broken into, nothing can be written or deleted. Only the indexer writes.
signed ingest
HMAC on every indexer pushShared secret in Worker secrets and the VPS env. Wrong or missing signature is 401 before anything is parsed.
validate
zod on every routeMints base58, 32 to 44 chars. Timeframes from a list. Limits capped at 500. Anything else is 400 and never reaches the DB.
no injection
Parameterised queries onlypostgres.js tagged templates bind every value. No string-built SQL anywhere.
limits
Per IP: 20 requests/s, 3 sockets, 10 subscriptions eachCloudflare rate rules at the edge, message size 1KB, idle sockets closed after 60s without a pong.
fail closed
Bad input 400, DB down 503Never a stack trace. Logs carry a request id and no secrets.
auth, later
v1 is public chain data, no loginPhase 2 adds Privy: the phone sends a JWT, the Worker verifies it, and only then touches anything user-specific.
