Cases

crash
Process diessystemd restarts in 3s. Resumes from the cursor. Replay fills the gap. Tested above.
stall
Connected, nothing arrivingCron watchdog restarts it if the cursor hasn't moved for 3 minutes.
db error
Postgres refuses a writeFound tonight. Before: cursor moved on, trade lost. Now: connection dropped, replay from the cursor, nothing skipped.
replay time
Replayed trades get the wrong timeFound tonight. Was using receive time. Now asks the chain for the real block time of each slot.
two swaps
Two swaps of the same program in one instructionFound tonight. The second was dropped as a duplicate. Now each event gets its own position in the transaction.
decimals
Token first seen mid-life with 9 decimalsFound tonight. Was assumed 6, price off by 1000×. Now reads the mint before the first trade.
new stock
StonkFun adds a stockFound tonight. The filter never included it until restart. Now checks hourly and resubscribes.
> 24h down
Longer than the replay windowRun the backfill once. Catalog and charts return from Raydium and pump.fun. Trade tape for the gap is gone.
disk dies
The VPS is lostPostgres is on this disk only. Nightly dump elsewhere is not set up yet. Say yes and it is.
fork
A confirmed trade gets dropped by the chainRare, under 0.1%. We index at confirmed like every terminal does. Accepted.
